WHAT IT DOES

Less manual renaming.
More organized libraries.

Built for the messy filenames you get from downloads, rips, and mixed folders.

⌕

Match with TMDB

Search for a series and load its episode list to compare your filenames against official episode titles.

✦

Smart filename matching

Recognizes season and episode patterns like S01E02 and 1x02, and compares episode titles while ignoring common release tags.

▤

Preview before changes

See original filenames, suggested names, match details, and confidence before applying any renames.

↳

Folder scanning

Scan a single folder or include subfolders. Choose whether episode titles are included in the final filenames.

✓

Conservative matching

Only confident matches are approved. Files that need a closer look are marked for review and skipped.

⌁

Common video formats

Supports MKV, MP4, AVI, MOV, WMV, M4V, TS, WEBM, MPG, and MPEG.

THE RESULT

From messy to consistent.

Keep episode files easy to sort, identify, and browse.

QUICK SETUP

Up and running in minutes.

You'll need Python and a TMDB API key to run the app.

01

Get a TMDB API key

Create a TMDB account, go to your account settings, open the API section, and request an API key.

TMDB API settings ↗
02

Download the files

Download the Python script and Windows launcher below. Keep both files together in the same folder.

03

Launch the app

Install Python 3 if needed, then double-click the .bat launcher. Enter your API key in the app.

04

Scan and preview

Find your show, load episodes, choose your media folder, and click Scan & Match.

05

Approve renames

Review the preview. When you're ready, click Rename Approved Matches. Files marked Review are not renamed.

Before you rename
