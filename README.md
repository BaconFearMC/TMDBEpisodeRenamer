# TMDB Episode Renamer - GitHub Pages

This is a ready-to-publish GitHub Pages website for TMDB Episode Renamer.

## Publish

1. Create a GitHub repository (or use an existing repository for your site).
2. Upload **all files and folders** from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your branch (usually `main`) and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish your site.

The downloads are linked to these filenames and must be in the repository root:
- `TMDB_Episode_Renamer.py`
- `Launch_TMDB_Episode_Renamer.bat`

The site uses `index.html` and `style.css`. `assets/favicon.svg` is the favicon.

## Update downloads

Replace the Python script and launcher with newer versions, preserving the same filenames, to update the download links.
